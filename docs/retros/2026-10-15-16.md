# Retro: fixes and 23a, 2026-10-15 and 16

Milestone: [Fixes 1 (2026-10-15–16)](https://github.com/TommiContursi/Polku/milestone/14?closed=1), closed.
What shipped: the review's findings #65, #66, #67, #69, #72 and #74, then
#88, #93, #102, #104, #105 and #112, phase 23a (#111) and the docs PRs #77,
#82, #91, #98 and #103. Claude Code sessions and Codex worked side by side, claiming issues
in comments.

## What cost us

**Too many sessions at once hit the usage limits.** Up to three Claude Code
sessions and Codex ran in parallel. Three sessions record reaching the limit
and waiting for it to reset; one spent most of its share rerunning the full
smoke suite (see the flaky checks below).
- *From now on:* two sessions at a time unless the user asks for more (in
  AGENTS.md). Run
  only the smoke groups you touch while working, and the full suite once
  before the PR. Leave a hand-over note, so a session stopped by the limit
  isn't redone.

**Squash-merging #116 left the stacked #117 in conflict.** #117 was branched
from #116's branch and carried its commits. The repo squash-merges, so #116
landed as one new commit (`8442564`); GitHub moved #117 onto `main`, where
the old copies of the same changes conflict. #124 is stacked on #117 and is
next in line.
- *From now on:* when the PR below yours is squash-merged, rebase yours onto
  `main` without its commits (`git rebase --onto origin/main <old base>`)
  before asking for a review. Stack only when waiting would block you. (In
  AGENTS.md.)

**A flaky smoke check cost full runs until #100.** The Weather-highlight
check (#74) failed about one run in three, on `main` as well, so #79, #81
and #94 each needed reruns before anyone could call them green. #100 made the
checks wait for the frame instead of a fixed time. Two more turned up after
it: the stops check failed early in the morning (#112, fixed in #113), and
the avoid check reads its toast too late (#99, still open).
- *From now on:* a check that fails sometimes gets an issue the same day and
  is fixed before the next phase starts. #99 is in Fixes 2.

**Testing another branch in the shared checkout gave wrong results.** While
#64 was verified in the main Polku folder, a forked session switched that
folder's branch, so half the suite tested `main` and failed with the bug #64
fixes. The #67 session also checked out `main` there mid-run.
- *From now on:* verify another branch in a worktree of its own, served on
  its own port, never by switching the shared checkout (now in AGENTS.md).

**Parallel Fix PRs fought over the status table.** #79 and #81 added ROADMAP
rows in the same place as Codex's #64, so whichever merged second conflicted.
#82 stopped Fix PRs adding rows; milestones now replace the table.

## Kept

- Every finding as its own issue, claimed in a comment with the branch.
- Hand-over notes for long fixes.
- A smoke check that fails before each fix and passes after it.
